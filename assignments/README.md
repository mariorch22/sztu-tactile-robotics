# 《触感机器人》课程实验报告要求

本课程需提交**三份实验报告：两份个人报告，一份团队报告**。

**报告一：触觉仿真系统（个人完成并提交）**

本实验需要你搭建触觉仿真环境，并在平台上运行抓握实验。按照 [Lab 1](../lab1/README.md) 完成环境安装与仿真运行验证，再按照 [Lab 2](../lab2/README.md) 更换物体、调整参数或控制策略，观察抓握结果的变化。

报告应包含**环境说明、关键步骤截图、参数与结果对比，以及完成情况**。按操作顺序组织截图，每张图简要说明进行了什么操作、观察到什么结果。明确写出**目前完成到哪一步**；遇到问题时，记录报错、尝试过的解决方法及尚未解决的问题。

**报告二：触觉数据分析与学习（个人完成并提交）**

本实验需要你完成 [Lab 3](../lab3/tactile_analysis/README.md) 的触觉数据分析和 [Lab 4](../lab4/README.zh-CN.md) 的模型学习，将两部分结果整理为一份报告。

**Lab 3：数据分析。** 检查数据有效性与采样质量，比较阈值 **10 与 20** 下的分析结果，并运行合成数据的面积／压力示例。报告中展示主要分析图表，解释阈值变化的影响。

**Lab 4：模型学习。** 运行预测与 latent 映射实验，比较参数和模型结果。报告中提交**一张三轴预测图、一张 latent 图和一张参数／误差对比表**，并从以下问题中**任选两题回答**：历史信息为什么可能帮助预测滞后？直接 MLP 为什么可能优于 latent 映射？自重建为什么不等同于跨模态预测？

**报告三：触觉机器人开放课题（团队完成并提交）**

团队从以下三个方向中**选择一个**，完成调研或实验。

**方向一：文献调研与方案设计。** 查阅最新触觉研究文献，比较已有方法，提出团队自己的研究思路。报告应说明研究问题、已有工作的不足、提出的方案，以及计划如何验证。

**方向二：基于触觉的自主抓取。** 开展机器人自主抓取实验，说明触觉信息如何参与决策或控制。报告应介绍系统与方法，展示实验过程和结果，并分析成功与失败的原因。

**方向三：千觉 UMI 设备数据采集与策略迁移。** 使用课程提供的千觉 UMI 设备采集数据，开展模仿学习/VLA策略训练和迁移测试。报告应说明采集任务、数据规模与质量、训练方法、迁移目标及测试结果。

无论选择哪个方向，报告都应说明**选题目标、工作过程、核心成果、完成情况和局限**，并列出参考文献。

**团队贡献与签名：**报告末尾须列出每位成员的姓名、学号、具体工作、对应成果和贡献比例。贡献比例合计 **100%**，由全体成员确认；**每位成员须签署本人的电子签名并注明日期**。

**通用要求：** 个人报告注明姓名和学号，团队报告列出全部成员。使用本人或本团队的实验截图和结果，**如实说明完成程度**。
